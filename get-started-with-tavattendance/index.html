Get started with TAVAttendance

A step-by-step guide to installing TAVAttendance on an iPad using AltStore, since it isn't distributed through the App Store.

Step 1

Install AltServer on your computer

AltServer runs on a Mac or PC and is what installs AltStore onto your iPad over USB or Wi-Fi.

  1. Install iTunes and iCloud directly from Apple — not the Microsoft Store versions.
  2. Download and run the AltServer installer for Windows, following the official guide.
  3. Search for “AltServer” in the Start menu and run it as administrator; allow any network access prompts.
  4. Connect the iPad by USB, unlock it, and tap “Trust” if prompted.
  5. Open iTunes, select the iPad, and enable “Wi-Fi sync.”
  1. Download AltServer for macOS and drag it into /Applications, then launch it.
  2. Connect the iPad by USB, unlock it, and tap “Trust” if prompted.
  3. In Finder, select the iPad in the sidebar and enable “Show this iPad when on Wi-Fi.”
Step 2

Install AltStore on the iPad

  1. Click the AltServer icon (menu bar on macOS, taskbar on Windows) → Install AltStore → choose your iPad.
  2. Enter your Apple ID email and password when asked.
  3. Wait for the “Installation Successful” notification. The AltStore app will appear on the iPad's home screen.
Your Apple ID and password are sent directly to Apple to sign the app — not to AltStore or thegoodcompany.
Step 3

Trust AltStore on the iPad

  1. On the iPad, go to Settings → General → VPN & Device Management, select your Apple ID, and tap Trust.
  2. If on iOS 16 or later, also enable Settings → Privacy & Security → Developer Mode, then restart the iPad when prompted.
Step 4

Install TAVAttendance

  1. Open the AltStore app on the iPad.
  2. Go to the Browse tab → the sources icon (top-left) → Add Source.
  3. Enter this source URL: https://dash.thegoodcompanysg.dev/altstore.json
  4. Open the new source, find TAVAttendance, and tap Install. Confirm with your Apple ID if asked again.
Keep it working

Weekly refresh

Apple's free developer signing expires every 7 days. To keep TAVAttendance working:

  • Keep AltServer installed and running on a computer on the same Wi-Fi network as the iPad.
  • Open the AltStore app on the iPad at least once a week — it will refresh automatically in the background if AltServer is reachable.
If TAVAttendance stops opening, it likely expired — open AltStore on the iPad with AltServer running nearby to refresh it.
